# Tutorials

Ordered lessons you follow at your terminal. Each builds on the one before, and each shows the
commands and what you should see.

There is one track.

| Track | What you learn | Needs |
|---|---|---|
| [1. ynr on a laptop](laptop/README.md) | The whole path on one machine: build ynr, start `ynr serve`, send it telemetry the way a vendor CLI does, watch it arrive, ask what happened, and see what is left on disk. No cloud, no model, no other YN tool. | Go, git, a C toolchain, curl |

The other YN tools have tutorials of their own: [ynh](https://github.com/eyelock/ynh/tree/develop/docs/tutorial),
[ynm](https://eyelock.github.io/ynm/#/tutorial/README) and [ynf](https://eyelock.github.io/ynf/#/tutorial/README).
You don't need them first.
